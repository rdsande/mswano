# Mswano Apartments

Premium apartments website built with the same core frontend stack and motion feel as the Meethaq reference project.

## Stack

- Next.js 14 App Router
- React 18
- TypeScript
- Tailwind CSS v4
- Framer Motion
- Iconoir React

## Getting started

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Current scope

- Frontend landing page
- Autoplay muted YouTube video hero
- Premium blurred fade reveal animations
- Residence cards
- Amenities section
- Enquiry form UI placeholder
